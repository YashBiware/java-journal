## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/java-dsa.git
   cd java-dsa
   ```

2. **Compile a file**
   ```bash
   javac path/to/FileName.java
   ```

3. **Run it**
   ```bash
   java path/to/FileName
   ```

> No external dependencies — pure Java (JDK 17+).
